# Map boundary data

`ukraine-border.geojson` contains the Ukraine feature extracted from Natural
Earth's 1:10m Admin 0 Countries, Ukraine point-of-view dataset (version 5.1.1).

Source: https://github.com/nvkelso/natural-earth-vector/blob/master/geojson/ne_10m_admin_0_countries_ukr.geojson

Natural Earth data is in the public domain.
